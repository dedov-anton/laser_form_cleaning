# laser_form_cleaning

Генератор траекторий лазерной очистки форм Pirelli: единое GUI, модульные генераторы поверхностей, универсальный экспорт.

## Запуск

```bash
python main.py
```

## Архитектура

```
GUI (единое окно)
  ├── Общие параметры формы (луч, поза матрицы 6D)
  ├── Низ формы — bottom_ring  [реализован]
  ├── Верх формы — top_ring     [заглушка]
  └── Поверхность качения — cylinder_wall [реализован]

Генератор → WorkTrajectory (локальная СК) → Перенос по 6D → config/project.json
                                              → экспорт STEP / УП робота
```

| Слой | Путь | Назначение |
|------|------|------------|
| Общие типы | `src/common/` | `Pose6D`, `WorkTrajectory`, `FormProject` |
| Генераторы | `src/generators/` | Расчёт траекторий по поверхностям |
| Хранение | `src/storage/` | `project.json`, сериализация траекторий |
| Экспорт | `src/exporters/` | STEP (XCAF), УП робота (заглушка) |
| Трансформации | `src/transforms/` | Перенос `WorkTrajectory` по 6D-позе (Elite sxyz) |
| GUI | `src/gui/` | Shell + секции по поверхностям |

### Генераторы

- **bottom_ring** — нижнее кольцо: радиальные проходы, профиль, сектор O→I, наклон инструмента.
- **top_ring** — верх формы (в разработке).
- **cylinder_wall** — внутренняя стенка цилиндра: 8 секторов по 45°, вертикальные проходы сверху вниз, авто-проходы по ширине луча.

Каждая секция GUI имеет **свои** старт/финиш и набор кнопок: **Создать траекторию**, **Переместить по 6D позе**, **Экспорт STEP**, **Создать УП**.

### Перенос по 6D-позе

1. **Создать траекторию** — расчёт в локальной СК (центр кольца в XY=0).
2. Задать **X Y Z Rx Ry Rz** в блоке «Поза матрицы / базы» (мм и градусы, Static XYZ / Elite).
3. **Переместить по 6D позе** — жёсткий перенос всей траектории (точки, оси инструмента, сегменты). Локальная копия сохраняется; повторное нажатие с другими значениями пересчитывает перенос от локальной копии, без накопления.

### WorkTrajectory

Универсальный «сырой» результат генератора: последовательность поз инструмента (`poses`), перемещения (`travel_segments`), рабочие сегменты (`work_segments`), справочная геометрия для визуализации. Экспортёры работают только с этим форматом.

## Конфигурация

- `config/project.json` — параметры проекта и сохранённые траектории (не в git).
- При первом запуске выполняется миграция из `config/last_params.json`, если он есть.
